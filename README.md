# 🖼️ Image Uploader Website

A web application that allows users to upload images through a simple and user-friendly interface.

## 🚀 Features

* Upload images from your device.
* Store and manage uploaded image information.
* Display uploaded images using their URLs.
* Simple and user-friendly interface.
* Backend API for handling image uploads.

## 🛠️ Technologies Used

### Frontend

* React.js
* Vite
* JavaScript
* CSS

### Backend

* Node.js
* Express.js
* MongoDB
* Multer
* ImageKit

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Archanachaurasiya30/image-uploader-website.git
```

### 2. Open the Project

```bash
cd image-uploader-website
```

### 3. Setup the Backend

Open the backend folder and install the dependencies:

```bash
cd backend
npm install
```

Configure your required environment variables locally before starting the backend.

### 4. Setup the Frontend

Open a new terminal:

```bash
cd frontend
npm install
npm run dev
```

Open the local URL displayed in the terminal to access the frontend.

## 🔐 Environment Variables

Keep your credentials and API keys private. Do not upload your `.env` file to GitHub.

Create your own local `.env` file with the environment variables required by your backend.

The goal of this project is to understand image uploading, frontend-backend communication, API development, and image storage integration.
